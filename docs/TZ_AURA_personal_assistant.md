# Техническое задание

## Проект: персональный ассистент AURA на Java

Версия документа: 1.0  
Дата: 05.05.2026

## 1. Общие сведения

AURA — персональный голосовой и текстовый ассистент для управления компьютером, работы с файлами, поиска информации, общения с нейросетью и помощи пользователю в ежедневных задачах.

Проект реализован как Java backend с локальным веб-интерфейсом. Основная идея проекта — создать не простой чат-бот, а ассистента с памятью, командами, сценариями, безопасной автоматизацией и естественным общением.

## 2. Назначение проекта

Система предназначена для локального использования на ноутбуке или компьютере пользователя. AURA принимает команды голосом или текстом, выполняет доступные действия, отвечает понятным человеческим языком и помогает управлять рабочим процессом.

## 3. Цели разработки

- Создать персонального ассистента с современным интерфейсом и голосовым управлением.
- Реализовать управление приложениями, браузером, файлами, Word-документами, задачами и напоминаниями.
- Добавить AI-ответы через Gemini/OpenAI с автоматическим fallback-режимом.
- Сделать ассистента более естественным: память, профиль пользователя, синонимы, контекст и привычки.
- Обеспечить безопасную работу с опасными командами, особенно удалением и очисткой данных.

## 4. Пользователи системы

- Основной пользователь: владелец компьютера, которому нужен быстрый локальный помощник.
- Дополнительный пользователь: преподаватель или проверяющий, оценивающий работу проекта.

## 5. Функциональные требования

### 5.1. Голосовой и текстовый ввод

- Пользователь может вводить команды через поле ввода.
- Пользователь может использовать микрофон через Web Speech API.
- Ассистент должен озвучивать ответы с выбранным голосом, скоростью, тоном и громкостью.
- Поддерживается wake word режим: Аура, AURA, Ассистент.

### 5.2. Базовые команды

- Приветствие, дата, время, погода, новости, валюты, шутки и факты.
- Расчеты: посчитать выражение, проценты, простые математические задачи.
- Перевод слов и фраз, включая русский, английский, японский и казахский языки.

### 5.3. Управление компьютером

- Открытие и закрытие программ: блокнот, калькулятор, браузер, проводник, терминал и другие.
- Открытие диспетчера задач.
- Управление вкладками браузера: новая вкладка, закрытие, переключение, обновление, переход на сайт.
- Открытие настроек Wi-Fi и Bluetooth.
- Создание скриншотов и чтение буфера обмена.

### 5.4. Работа с файлами и документами

- Создание файлов и папок на рабочем столе или в пользовательских папках.
- Открытие файлов и папок на главном экране компьютера.
- Безопасное удаление через корзину AURA, без прямого уничтожения важных данных.
- Создание и открытие Word-документов .docx.
- Поиск файлов по смыслу и названию в Рабочем столе, Документах и Загрузках.

### 5.5. AI и интеллектуальная обработка

- Если запрос не является системной командой, AURA обращается к подключенной нейросети.
- Поддерживается режим ai.provider=auto: сначала основной AI, затем запасной OpenAI.
- Команда "проверь нейросеть" показывает состояние AI без раскрытия API-ключей.
- Ассистент должен понимать синонимы и разговорные фразы: открой/запусти, найди/поищи, включи/поставь, удали/сотри.
- Ассистент не должен отвечать как сухая нейросеть; стиль должен быть живым и дружелюбным.

### 5.6. Память, задачи и сценарии

- AURA сохраняет заметки пользователя и может выводить их по запросу.
- AURA запоминает профиль пользователя: имя, город, стиль общения и другие параметры.
- Поддерживаются задачи: добавить задачу, показать задачи, отметить выполненной.
- Поддерживаются напоминания с выводом в интерфейсе и озвучиванием.
- Поддерживаются сценарии: режим учебы, режим работы, режим отдыха и пользовательские сценарии.
- Поддерживаются привычки: если AURA слышит заданную фразу, она выполняет связанное действие.
- Поддерживаются обучаемые команды: пользователь может научить AURA новой фразе.
- Ведется журнал действий: пользователь может спросить, что AURA делала сегодня.

### 5.7. Agent mode

- Agent mode выполняет безопасные файловые задачи: поиск PDF, сортировка загрузок, переименование по дате.
- Agent mode не должен удалять файлы без подтверждения пользователя.
- Agent mode работает только в пользовательских папках и не трогает системные директории Windows.

## 6. Нефункциональные требования

- Приложение должно запускаться локально через start.bat.
- Backend должен работать на http://localhost:8080.
- Интерфейс должен быть современным, адаптивным и отличаться от стандартных учебных проектов.
- Ответы ассистента должны быть короткими, понятными и без лишних технических путей.
- Проект должен собираться Maven-командой mvn -q -DskipTests package.
- Секретные ключи API должны храниться только в aura.properties и не попадать в Git.

## 7. Архитектура системы

Проект построен по клиент-серверной архитектуре. Frontend отвечает за интерфейс, чат, голосовой ввод и озвучивание. Backend на Java принимает команды, маршрутизирует их, выполняет системные действия, обращается к AI-сервисам и сохраняет данные в SQLite.

- Frontend: HTML, CSS, JavaScript, Web Speech API, Speech Synthesis API.
- Backend: Java 21, Javalin, Gson, OkHttp, SQLite JDBC.
- База данных: SQLite файл aura.db.
- Конфигурация: aura.properties и aura.properties.example.
- Точка входа: Main.java.

## 8. Основные модули

- CommandManager — центральный маршрутизатор команд, синонимов, follow-up запросов и подтверждений.
- DatabaseService — работа с памятью, историей, профилем, задачами, сценариями, привычками и журналом.
- GeminiService — подключение Gemini/OpenAI, fallback и диагностика AI.
- SmartAssistantService — умное определение намерений пользователя.
- FileAutomationService и FileSearchService — создание, открытие, перемещение, безопасное удаление и поиск файлов.
- WordDocumentService — создание и открытие Word-документов.
- ReminderService — напоминания и их доставка во frontend.
- SystemTrayService — иконка AURA в системном трее Windows.

## 9. REST API

- GET /ping — проверка доступности backend.
- POST /api/command — отправка команды ассистенту.
- GET /api/history — история диалогов.
- GET /api/reminders/due — получение сработавших напоминаний.
- GET /api/status — статус системы и памяти Java.
- GET /api/settings и POST /api/settings — настройки AURA.
- GET /api/tasks — список задач.
- GET /api/actions — журнал действий.

## 10. Требования к безопасности

- API-ключи не должны храниться в исходном коде.
- Файл aura.properties должен быть добавлен в .gitignore.
- Удаление важных данных должно требовать явного подтверждения: "да, подтверждаю".
- Системные директории Windows не должны изменяться файловыми командами.
- Ответы AI-диагностики не должны показывать полный API-ключ.

## 11. Сценарии использования

- Пользователь запускает start.bat, открывает http://localhost:8080 и видит интерфейс AURA.
- Пользователь говорит: "привет" — AURA отвечает голосом.
- Пользователь говорит: "сводка дня" — AURA показывает город, задачи и напоминания.
- Пользователь говорит: "найди последний Word документ" — AURA показывает найденные документы без длинных путей.
- Пользователь говорит: "удали все файлы в загрузках" — AURA останавливается и просит подтверждение.
- Пользователь говорит: "когда я скажу домашка, открой последний Word документ" — AURA запоминает новую команду.

## 12. Критерии приемки

- Проект успешно собирается командой mvn -q -DskipTests package.
- Сервер запускается через start.bat и отвечает pong на /ping.
- Frontend открывается в браузере и показывает статус ONLINE.
- Работают базовые команды: привет, дата, время, помощь.
- Работают команды файлов и Word-документов.
- Работают задачи, сводка дня, журнал действий, сценарии и настройки.
- Опасные действия не выполняются без подтверждения пользователя.
- AI-ключи не попадают в Git.

## 14. Порядок запуска

- Установить Java 21 и Maven.
- В файле aura.properties указать рабочие API-ключи Gemini/OpenAI при необходимости.
- Запустить проект командой .\start.bat.
- Открыть http://localhost:8080.
- Проверить работу командой /ping или командой "привет" в интерфейсе.

## 15. Ограничения и риски

- AI-ответы зависят от наличия рабочего API-ключа и лимитов провайдера.
- Голосовое распознавание зависит от браузера и разрешения на микрофон.
- Некоторые системные команды зависят от Windows и прав пользователя.
- Agent mode специально ограничен безопасными пользовательскими папками.

## 16. Итог

Проект AURA соответствует цели разработки: создан персональный Java-ассистент с веб-интерфейсом, голосом, памятью, AI fallback, управлением компьютером, файлами, задачами, сценариями и безопасной автоматизацией. Проект готов к демонстрации и дальнейшему развитию.
